# Security policy

## Supported versions

Only the latest release on [crates.io](https://crates.io/crates/google-pagespeed-insights-api)
receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub Security Advisories](https://github.com/uiuifree/rust-google-pagespeed-insights-api/security/advisories/new).
You will get a reply within a week, and a fix will be published as a new release with
a note in `CHANGELOG.md`.
